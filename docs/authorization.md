# データ・権限の正本（確認待ち案）

Issue #2。2026年11月8日。以下は承認前の提案であり実装の許可済みルールではない。

| 操作 | 同じタブの利用者 | 別タブ・別端末の利用者 | 主催者・サーバー |
| --- | --- | --- | --- |
| 公開教材を見る | 許可 | 許可 | 許可 |
| メモを入力・閲覧・編集 | 自分のタブのみ | 他タブのメモは取得不可 | 取得不可 |
| 行動文をコピー・印刷 | 本人が確認した文のみ | 他タブの文は取得不可 | 取得不可 |
| 記録を消す | 自分のタブの専用キーのみ | 他タブを操作不可 | 遠隔操作なし |

## 保存と送信の提案

- sessionStorageに一時保存。最終操作から2時間で期限切れ。
- 復帰・表示・操作時に期限を確認し、期限後は保存値と表示を破棄する。
- 保存不可時はメモリのみで継続し、復元できない旨を案内する。
- 壊れた値は表示せず、このアプリのキーだけを消す。
- 終了ボタンで同じタブの専用キーだけを消す。他サービスの履歴・クリップボードは消さない。
- 別タブにデータを複製する導線を作らず、外部AIのリンクにnoopenerを付ける。
- 同じタブ・ブラウザープロファイルを使う他の人は端末内の記録を見られる可能性がある。共用端末では終了ボタンを使う。
- サーバーDB、メモ送信API、参加者一覧、独自の入力ログは設けない。
- AIへコピーする文にメモを自動追加しない。本人が外部AIで入力した内容はそのサービスの条件に従う。
- URL・QRに入力値を含めない。配信元への通常のアクセス通信は発生する。
